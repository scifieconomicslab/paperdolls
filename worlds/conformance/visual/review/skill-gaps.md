# Skill gaps found rebuilding the conformance world from the markdown skills

Test: rebuild `worlds/conformance` using only `skill.md`, `paperdolls-art-direction`, `paperdolls-scene-craft`
(+ every recipe) and `paperdolls-beauty-review`, without the legacy kit. Result: a scene in
`page/src/scene/` (palette, util, layout, pipeline, buildings, streets, nature, life, data, camera, index) that
reached **3.8 / 5 after four rounds (FAIL: value structure 3, edge and framing 3)**. Every gap below is something
I had to guess, fix by trial or work around. Ordered by how much it cost.

## What worked as written

- The house-style table, the build order, the three zoom levels and the snapshot contract were enough to structure the code.
- palette-method's OKLCH bands and the `oklch()` snippet gave a coherent palette on the first try (teal needed C 0.085 to stay in gamut, as the recipe warns).
- The ink shader, shadow fitting and the gable unit geometry worked as given.
- Composition §1's checklist found the real problems (no centre, no gradient, no landmark).
